# Build report — sc1 · Core rules, sources, scanner, Worker API + D1

## Contract questions
1. **`rig-harness` / `check()` isn't installed** on this machine (no binary or module anywhere). Negative controls are
   done by hand instead (break, run, record the red line, restore) and written up below.
2. **§4.1 "from STATUS text (only when class unknown)"** — I read "class unknown" as *class missing or not in the
   table*. So: a class in the table decides; otherwise the STATUS text rules; otherwise `other`. A class that isn't in
   the table always goes into `unmapped_classes`, even when the STATUS text gave a status. `status_basis` is `none`
   when neither matched.
3. **§4.4 more than one region named** (e.g. "all Central schools and all Western schools"): the contract gives one
   `scope_region`. I take the earliest phrase and `findRegionPhrase` reports `ambiguous: true`. Nothing uses that flag
   yet. The lead should decide: first region only, two notices, or `district`.
4. **§4.2 region check for status rows**: done on `school_text` only (as §4.2 says), not on the note. That way an
   unmatched row whose note says "like all schools in the Central region" doesn't close 77 schools.
5. **§3.2 text notice scope/status**: both come from `quote` (not `source_text`), so a region phrase in a
   *different* notice in the same box can't leak into this one.
6. **`CSFP_SHORT` and French elision**: `normName("École l'ENVOL")` is `ecole lenvol` (apostrophe deleted), so
   `envol` would never match as a whole word. I allow a single `l`/`d` before a short name (`(?:^| )[ld]?envol`).
7. **Stale reason text when NLSchools was never checked**: §4.5 has "since {time}", but there's no time to fill in. I
   use "We haven't been able to check NLSchools yet. Check nlschools.ca or call the school."
8. **`stale_text`** isn't fixed in the contract; mine (from `core/schedule.js` `staleText`):
   `last_attempt_failed` → "We couldn't reach the NLSchools list at 6:40 AM. Statuses below are from 6:35 AM."
   ("couldn't read" for `format_changed`); `overdue` → "We haven't been able to check the NLSchools list since
   6:35 AM."; `never_checked` → "We haven't checked the NLSchools list yet."
9. **Ingest re-derives everything that isn't verbatim.** After re-verification the Worker re-runs `classifyNotice`
   (status, scope, matches) from the verified fields and its own school list. A payload can't bring its own
   `matches: exact`.
10. A nulled `list_date_text` also nulls the notice's `list_date` (the notice id is unchanged).
11. **CSFP schools and `stale`**: a CSFP school's `stale` flag is the `csfp-news` health. `unmatched_in_region`
    counts unmatched `nlschools-status` rows for any school with a region, CSFP included.
